PipelineAgent

An agent that watches data pipelines, repairs the breaks it can, opens a pull request and merges it after a scripted gate passes, and hands the rest to a person with one issue.

Most monitoring asks whether a job exited 0. This asks whether fresh data landed. A job that succeeds while writing nothing is the failure it is built around.

Everything below is live: 8 public feeds, checked every hour, rendered by the loop itself.

Faults are injected between the HTTP client and the parser; everything downstream reacts as to a real upstream change. Baseline: detectors without the agent find the same failures at the same time, then wait for a person. Detection time is bounded below by each feed's SLA: 3 hours for the hourly feeds, 30 hours for IESO's once-a-day file.

How it works

Watch
Fetch7 public feeds + a canary

Hourly. Every raw response is archived by content hash, so any failure can be replayed byte for byte later.

Storeappend-only, vintaged

Rows are never overwritten; each carries captured_at. The warehouse is the only source the detectors read.

Detectdata, not exit codes

Three axes per feed: how long since we wrote, how old the data's own clock is, whether values froze. UNKNOWN is never green.

Ledgerfindings + dispositions

A finding is one not-OK stretch. It carries exactly one current disposition, and FIXED requires evidence.

Act
Triagea rule table, no model

Schema drift is patchable; a timed-out source, a green job with dead data, a frozen value are not, and are escalated with one issue.

Replayreproduce before fixing

The archived failing bytes are fed to the current code in a sandbox with the network off. If the failure does not reproduce, nothing is patched.

Patchthe only model call

A model proposes a new fetcher module and one test. It only proposes; it never decides.

Gatea script is the judge

Diff linter (no SLA, detector, test or policy edits), replay (failing bytes must land rows, healthy bytes must not change) and the whole test suite.

Merge + deployautomatic on PASS

Squash merge, Cloud Build, and a check that the running job's code hash matches the commit.

Verifythe next live runs decide

Cleared within two runs: FIXED with the PR as evidence. Still open: automatic revert. Three failures: ESCALATED.

Guard the guard
Scenario evalsevery change, offline

Recorded drills and incidents replayed through the real code; guarded so answers cannot drift silently.

Weekly drillsthe live path

A canary is broken on purpose every Wednesday; a wrong or missed verdict opens an issue.

Dead-man switchthe monitor's own pulse

No heartbeat for 26 hours turns this whole page red, computed in your browser.

Learningbounded

Findings a person settles become replayable test drafts. The system grows its tests, never edits its own judge.
